# Coach IQ: exercise library

Written by `npm run iq` from `exercises.json`. Do not edit this page: change
`exercises.json` and run it again.

177 exercises. **Care with** lists the joints an exercise loads and plain facts about it;
which conditions call for care with which is in Coach IQ's principles.

Facts used under Care with: **high-impact** (jumping or running), **spinal-load** (a heavy load on the spine), **spinal-flexion** (rounding the spine), **spinal-rotation** (twisting the spine), **overhead** (arms overhead), **lying-on-back** (lying on the back), **lying-face-down** (lying face down), **inverted** (head below the heart), **balance** (a balance challenge), **breath-hold** (heavy bracing that tempts holding the breath), **floor-transfer** (getting down to the floor and up), **grip** (a hard grip).
